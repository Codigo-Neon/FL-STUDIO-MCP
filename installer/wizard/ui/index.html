Bienvenida

Esto va a configurar Claude para que controle tu FL Studio. Tarda unos 3 minutos.

Asegurate de tener FL Studio cerrado antes de empezar.

Diagnóstico del sistema

Chequeando qué está instalado…

    Vamos a descargar e instalar loopMIDI desde el sitio oficial.

    Esperando…

    Crear puerto MIDI virtual

    Creando un puerto llamado FL_MCP que FL Studio va a usar para recibir MIDI.

    Esperando…

    Instalar script en FL Studio

    Copiando device_test.py a la carpeta Hardware de FL Studio.

    Esperando…

    Registrar en Claude Desktop

    Editando claude_desktop_config.json (con backup automático).

    Esperando…

    Activar el script en FL Studio

    Este paso lo tenés que hacer vos en FL Studio. Seguí estas instrucciones:

    1. Abrí FL Studio
    2. Menú Options → MIDI Settings
    3. En la lista de Input, encontrá FL_MCP
    4. Hacé click en Enable y elegí FL_MCP en Controller type
    5. Click en Refresh y cerrá la ventana de Settings

    Probar la conexión

    Vamos a mandar una nota MIDI a FL Studio. Si todo está bien, vas a verla aparecer.

    Click "Probar" cuando estés listo.

    ¡Listo!

    Tu FL MCP Studio está configurado.

    De ahora en adelante vas a ver el ícono en la bandeja del sistema. Desde ahí podés ver el estado, reabrir este wizard o probar la conexión.
